# EventEase

College event registration and QR check-in demo.

## GitHub Pages demo

The Pages app saves demo data in this browser only. Data does not sync across browsers or devices.

Organizer demo PIN: `1234`

## Full Node server

The original zero-dependency server is included as `server.js`. Run `npm start` on a Node host. GitHub Pages cannot run the server, so the Pages demo uses local browser storage.
